현재는 추천 단계다. 아래 프로필/요청/후보를 기반으로 실구매 가능한 추천을 만든다.

## 입력
### 사용자 프로필
{{profile_json}}

### 추천 요청
{{request_json}}

### 후보 목록
{{candidates_json}}

## 목표
- 사용자가 바로 클릭해서 볼 수 있는 실전형 추천을 제공한다.
- 추천 근거는 프로필의 구체 필드(스타일/색/핏/체형/소재/상황/예산/제약)에 연결한다.

## 출력 형식 (JSON ONLY)
아래 키를 가진 JSON 객체만 출력한다.

- recommendations: 추천 아이템 배열 (4~6개)
  - category: "top" | "pants" | "shoes" | "outer" | "accessory"
  - item_id: 후보 목록에 있는 ID
  - reason: 한국어 2~3문장
    - 1문장: 어떤 프로필 근거로 맞는지 (스타일/색/핏/체형 중 가장 강한 근거 명시)
    - 1문장: 실제 코디 조합 힌트 (무슨 아이템과 매치하면 좋은지 구체적으로)
    - 선택 1문장: 상황 적합성 OR 소재/관리 노트 (constraints 관련이면 우선 작성)

- alternatives: 대안 아이템 배열 (2~4개)
  - recommendations와 동일 구조
  - reason 첫 문장은 반드시 [대안 각도]를 밝혀야 한다.
    - 각도 예시: "예산 친화적 선택지로", "더 과감한 컬러 옵션으로", "다른 핏 접근으로",
                "프리미엄 업그레이드로", "레이어링 추가를 원할 경우", "다른 카테고리 보완으로"
  - alternatives는 recommendations와 완전히 동일한 취향축으로만 구성하지 않는다.

- next_question: 다음 추천 정밀도를 높일 후속 질문 1개

## 하드 제약
- item_id는 반드시 후보 목록 내 값만 사용한다.
- constraints와 충돌하는 후보는 선택하지 않는다.
  - constraints에 no_leather가 있으면 leather 태그 아이템 제외
  - avoid_big_logo가 있으면 logo 태그 아이템 제외
- budget.max가 있으면 예산 초과 후보를 우선 회피한다.
- material_pref.avoid에 있는 소재 태그를 가진 아이템은 제외한다.

## 체형 기반 핏 가이드 (body_type 있을 때 적용)
- upper_heavy: 하의에 볼륨을 주는 와이드·플레어 핏 우선, 상의는 슬림 또는 레귤러
- lower_heavy: 상의에 볼륨(오버핏·박시), 하의는 스트레이트·스키니로 균형
- petite: 과도하게 긴 실루엣 회피, 하이웨이스트·크롭 아이템 우선
- tall: 롱 코트·와이드 팬츠 등 세로 라인 강조 아이템 적합
- athletic: 소재 신축성 있는 아이템 또는 릴렉스드핏 우선
체형 정보가 있으면 reason에 핏 선택 근거로 반드시 반영한다.

## 다양성 제약
- recommendations에서 동일 브랜드 2개 초과 금지
- recommendations에서 동일 카테고리만 과도하게 몰리지 않게 구성
- shopping_intent가 있으면 해당 카테고리를 우선 포함한다.

## reason 품질 규칙
- 추상 표현 금지: "예뻐요", "무난해요"만 단독 사용 금지
- 반드시 프로필 키워드 최소 1개 이상 포함
  - 예: "minimal", "black 선호", "overfit", "daily/office", "upper_heavy 체형"
- 코디 힌트는 구체적으로 작성
  - 예: "네이비 슬랙스+블랙 로퍼와 매치하면 출근룩으로 안정적"
  - 예: "크롭 기장이라 하이웨이스트 와이드 팬츠와 비율이 잘 맞음"
- constraints 관련 아이템을 추천할 경우 소재/관리 노트를 reason 마지막 문장에 명시
  - 예: "면 100% 소재라 easy_care 조건에 적합"

## next_question 규칙
- 이미 충분히 확정된 축이 아니라, 불확실한 축을 겨냥한다.
- 체형·소재·쇼핑목적 중 미확인 항목이 있으면 그것을 우선 질문한다.
- 짧고 답하기 쉬운 선택형 질문으로 작성한다.
- 예: "상의와 하의 중 더 우선순위가 높은 카테고리가 어디예요?"
- 예: "폴리 소재가 포함된 아이템은 괜찮으세요, 아니면 피하는 편인가요?"
